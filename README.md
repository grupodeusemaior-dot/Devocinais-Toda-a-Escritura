# Devocinais Toda a Escritura

Aplicativo web progressivo (PWA) com 565 reflexões do PDF **Toda a Escritura**, estruturadas em JSON e separadas por Novo e Antigo Testamento.

## Publicação no GitHub Pages
1. Extraia o ZIP.
2. Envie os arquivos e pastas desta pasta para o repositório GitHub.
3. Em **Settings → Pages**, selecione a branch e a pasta raiz (`/root`) para publicar.
4. Abra o endereço HTTPS publicado.

## Instalação
- **Android:** abra o site no Chrome e escolha “Instalar app” ou “Adicionar à tela inicial”.
- **iPhone:** abra o endereço no Safari, toque em Compartilhar e escolha “Adicionar à Tela de Início”.

O app possui cache offline, busca por título/referência, filtros por Testamento e controle do tamanho da leitura.

Os dados foram extraídos do PDF enviado. A paginação indicada no JSON corresponde à página física do PDF.
